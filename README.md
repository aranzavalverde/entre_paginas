# Entre Páginas
Red social literaria diseñada para conectar lectores, compartir reseñas de libros, descubrir nuevas lecturas y debatir sobre historias favoritas.

## Características principales
* **Estructura semántica en HTML5:** Secciones de inicio de sesión, Publicaciones, Crear Publicación, Perfil y Acerca de.
* **Diseño visual con CCS:** Estilos y diseño visual de la interfaz.
* **Interactividad con JavaScript:** Gestión de publicaciones, manipulación del DOM, sistema de "Me gusta", filtros por categoría y validación de formularios.

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript (ES6)
* Git y GitHub para control de versiones
